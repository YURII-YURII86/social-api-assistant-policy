Политика обработки данных Social API Assistant

Обновлено 13 октября 2026 года.

Social API Assistant — приложение для управления профессиональным Instagram-аккаунтом @yurii_yurii86. Оно использует официальный API Meta для публикаций, статистики, комментариев и ответов в Direct.

Какие данные обрабатываются

Для подключённого аккаунта: сведения профиля, публикации и их статистика. Для обработки обращений: доступные через Meta идентификаторы и текст комментариев, даты, сведения об отправителе и сообщения переписки в пределах предоставленных разрешений.

Для чего используются данные

Для выполнения выбранных владельцем аккаунта действий, анализа публикаций, подготовки ответов и выдачи материалов пользователям, которые запросили их кодовым словом в комментарии. Сообщения не рассылаются произвольным пользователям.

Хранение и передача

Данные обрабатываются программой на компьютере владельца аккаунта. Токены доступа хранятся в macOS Keychain. Локальная база хранит правила, измерения статистики, задания и журнал доставки с идентификаторами и результатами операций. Выбранные данные могут отображаться в используемом владельцем AI-клиенте, включая Codex; условия обработки этого клиента определяются его поставщиком и настройками владельца.

При подготовке публикаций выбранные файлы временно доставляются через HTTPS-ссылки Cloudflare в Meta. Пользовательские данные не публикуются в репозитории приложения. Материалы, выдаваемые по ссылкам, могут размещаться на сторонних сервисах, например Telegram; к ним применяются правила соответствующего сервиса.

Удаление и прекращение доступа

Владелец может остановить автоматические правила и отключить приложение через настройки «Приложения и сайты» Instagram. Для запроса удаления локальных данных, связанных с обращением, напишите @yurii_yurii86, указав своё имя пользователя и ссылку на публикацию или дату обращения. Не отправляйте пароли и токены. Подробности: инструкция удаления данных.

Контакт

Ответственный за работу приложения и запросы о данных: владелец аккаунта @yurii_yurii86.
